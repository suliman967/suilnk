# NMO screenshots

Placeholder SVGs live here so the case study section never looks broken.
To replace with real screenshots:

1. Export screenshots at roughly 1600x1000 (16:10) for the best crop in the
   main viewer. PNG or JPG both work.
2. Drop the files in this folder, e.g. `homepage.png`.
3. Open `src/utils/nmoData.js`, update the import path and swap the
   matching `image` value.

Add more entries the same way to extend the gallery — the section
component needs no changes.
